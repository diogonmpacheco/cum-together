# Cum Together Preview

This is the public preview build of Cum Together, an adults-only video-room concept where people can masturbate together without showing their faces.

Live prototype: https://diogonmpacheco.github.io/cum-together/

The source repository is private. This repository contains the built static prototype and public design-feedback docs.

The interface is available in English and European Portuguese (`pt-PT`) from the language switcher.
